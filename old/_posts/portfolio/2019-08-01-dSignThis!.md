### Project Description

**dSignThis!** is a decentralized petition platform developed as the final project for the [Blockchain Developer Bootcamp Spring 2019](https://consensys.net/academy/bootcamp/){:target="_blank"} organized by Consensys. This application allows users to create and sign petitions directly on the Ethereum blockchain, removing the need for third-party platforms like change.org.

The dApp leverages smart contracts to ensure that all petitions are transparent, immutable, and free from censorship. Users can interact with the platform through Metamask, ensuring secure and verifiable signatures on each petition.

### Contributions

Key contributions to the **dSignThis!** project include:

- **Smart Contract Development:** Wrote and deployed smart contracts using Solidity, ensuring secure and decentralized petition management.
- **dApp Interface:** Developed the front-end using React, integrating Web3.js to connect with Ethereum smart contracts.
- **Blockchain Integration:** Used Truffle and Ganache-CLI for local blockchain development and testing before deployment on the Ethereum Ropsten network.
- **Decentralized Storage:** Incorporated IPFS (InterPlanetary File System) for storing petition data in a decentralized manner (work in progress).
