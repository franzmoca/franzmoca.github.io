### Project Description

I was responsible for developing a custom ERC721 token smart contract for **Genuino World**, a startup specializing in the verification of the authenticity of items, such as football jerseys worn by players.

The project involved extending the basic functionalities of the ERC721 smart contract to store additional metadata directly on the blockchain. Additionally, an access control system was implemented to differentiate between three types of users, providing specific permissions and functionalities based on the user role.

In addition to the smart contract, I also developed a web application for managing the smart contract and a mobile wallet app to provide users with seamless interaction capabilities.

### Contributions

- **ERC721 Smart Contract Development:** Enhanced the basic ERC721 standard to include additional metadata storage and user roles.
- **Access Control System:** Implemented a robust access control mechanism within the smart contract, ensuring secure and role-specific interactions.
- **Web and Mobile Applications:** Developed both web and mobile applications to allow users to interact with the blockchain easily, integrating with Metamask and mobile wallets.
