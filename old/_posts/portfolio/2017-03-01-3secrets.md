### Project Description

**3 Secrets** is a companion app designed to enhance the gameplay experience of the "3 Secrets" board game, published by DaVinci Editrice. The app includes several features tailored to assist players during the game, such as a timer with customizable functions, tools to track character cards, and options to share game results on social media platforms.

The project was developed using the Ionic v1 framework and AngularJS, enabling it to run seamlessly as a cross-platform application on both Android and iOS devices. The app is designed with a Web View architecture, leveraging Cordova to bridge web technologies with native device capabilities.

The **3 Secrets** app has been actively maintained and updated since its initial release in September 2016, and it has achieved a significant user base with thousands of downloads on both Google Play and the App Store.

### Contributions

Key contributions to the **3 Secrets** app included:

- Developing the app using JavaScript, HTML5, and SASS within the Ionic v1 framework, ensuring a responsive and visually appealing user interface.
- Implementing the MVVM (Model-View-ViewModel) design pattern to manage the separation of logic and presentation, enhancing maintainability.
- Integrating social media sharing functionalities, allowing players to share their game results effortlessly.
- Ensuring cross-platform compatibility and performance optimization for both Android and iOS using Cordova.

### Challenges Overcame

Several challenges were encountered during the development of **3 Secrets**:

- **Cross-platform Development:** Ensuring consistent performance and user experience across different devices and operating systems.
- **Real-time Updates:** Implementing features like the game timer, which required real-time updates and precise timing across platforms.
- **Maintaining Legacy Code:** Updating and maintaining an app originally built on older frameworks like Ionic v1 and AngularJS, while ensuring compatibility with modern devices and OS versions.

### Accomplishments

The **3 Secrets** app achieved several key accomplishments:

- Successfully launched on both Android and iOS platforms, with continued maintenance and updates, reflecting its ongoing popularity.
- Garnered thousands of downloads, demonstrating its value to the gaming community and its role in enhancing the board game experience.
- Provided a stable and user-friendly application that integrates seamlessly with the physical board game, adding value and utility for players.
