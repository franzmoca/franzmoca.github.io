### Project Description

The **Fury of the Avatar Deckbuilder** is a single-page application developed in the summer of 2015, designed to support the creation and testing of decks for a custom collectible card game (CCG) prototype. The game was conceptualized by Martino Chiacchiera and Michele Piccolini. 

This web-based tool allowed users to easily create and manage card decks by hovering over card images. It ensured compliance with deckbuilding rules by enforcing limits and provided a seamless user experience through its responsive design. The application was built using PHP, SQL, HTML5/CSS, and JavaScript, with a focus on AJAX for dynamic content loading and Bootstrap for responsive styling.

### Contributions

I played a key role in the development of the application by:

- Designing and implementing the deckbuilder as a single-page application.
- Utilizing AJAX for real-time updates without requiring page reloads.
- Ensuring responsive design for accessibility on various devices.
- Integrating a feature to export decklists in a text format compatible with the online CCG platform, UnTap, facilitating streamlined playtesting.

### Challenges Overcame

During development, I encountered and overcame several challenges:

- **Maintaining Performance:** Ensured smooth performance when handling large card image datasets and complex user interactions.
- **Rule Enforcement:** Developed logic to enforce game-specific deckbuilding constraints dynamically.
- **Cross-Browser Compatibility:** Ensured that the application functioned correctly across different web browsers and platforms.

### Accomplishments

The final application successfully:

- Streamlined the deck creation process for users, enhancing playtesting efficiency.
- Provided a user-friendly interface that adhered to modern web design standards.
- Supported the prototype’s development by enabling quick iterations and feedback loops.

The Fury of the Avatar Deckbuilder was an integral tool in the early stages of game development, contributing significantly to the refinement of game mechanics and user experience.
