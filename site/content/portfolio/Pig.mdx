### Project Description

**Pig - Blockchain Game** is a scalable blockchain-based game developed as part of my master’s thesis, focusing on addressing the scalability challenges inherent to decentralized applications on the Ethereum blockchain.

The project builds upon my previous work on the Ethereum Data Channel, implementing a state channel solution specifically designed for two-player games. This solution is optimized to require minimal on-chain interactions, utilizing a commit-reveal scheme to ensure fairness and randomness in gameplay. Ideally, only two transactions are needed on the blockchain for the entire game, unless disputes arise between the players.

The smart contracts developed for this project are modular, allowing new games to be easily created by implementing specific game logic according to a standardized interface. This flexibility makes the system highly adaptable for various types of blockchain-based games.

### Contributions

Key contributions to the **Pig - Blockchain Game** project include:

- **State Channel Implementation:** Developed a state channel mechanism to minimize on-chain interactions while maintaining game integrity and fairness.
- **Smart Contract Design:** Created modular smart contracts to enforce game rules, enabling easy expansion to new games.
- **Commit-Reveal Scheme:** Optimized randomness in the game using a secure commit-reveal protocol, ensuring that all players have a fair experience.
- **Game Development:** Implemented a basic two-player game as a proof of concept, demonstrating the effectiveness of the state channel solution.
