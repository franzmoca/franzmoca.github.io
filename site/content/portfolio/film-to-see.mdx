### Project Description

**Film To See** is an Android application developed in February 2016 as part of a university project, in collaboration with Dan Rusnac, for a mobile programming exam. The app was designed to address a common problem among groups of friends—deciding which film to watch together.

The application allows users to create groups where members can add film titles, vote on their preferences, and comment on the options. By centralizing these activities, the app makes it easier for groups to reach a consensus on what to watch, streamlining the decision-making process. The backend of the app leverages a NoSQL database (OrientDB) to manage data, while the OMDb API is used to fetch film information.

### Contributions

Key contributions to the development of the **Film To See** app included:

- Designing and developing the Android application using Java, following Material Design guidelines for a modern and user-friendly interface.
- Implementing group-based features where users can add films, vote, and comment, enhancing user engagement.
- Developing the backend using PHP and OrientDB, and integrating the OMDb API to retrieve detailed movie information.

### Challenges Overcame

Several challenges were encountered during the development of the app:

- **Group Interaction Dynamics:** Ensuring that the voting and commenting features were intuitive and facilitated easy group interaction.
- **API Integration:** Successfully integrating the OMDb API to fetch accurate and comprehensive film data for users.
- **NoSQL Implementation:** Effectively using OrientDB as the NoSQL backend to manage the flexible and complex data structures required by the app.

### Accomplishments

The **Film To See** app was successfully developed and presented as part of the university exam, with notable accomplishments including:

- Creating a fully functional Android app that simplifies the process of choosing films within a group setting.
- Implementing a responsive and modern user interface that adheres to Material Design principles.
- Delivering a project that met all the academic requirements while providing a practical solution to a real-world problem.

The project was well-received and demonstrated the effective application of mobile development concepts and technologies.
