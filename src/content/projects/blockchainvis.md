Blockchainvis is my bachelor's thesis project: an interactive web application for visualizing Bitcoin transaction graphs.

The tool fetches transaction data from the Bitcoin blockchain and renders it as a force-directed graph using D3.js — allowing users to trace how value flows between addresses over time.

The visualization highlights patterns such as mixing services, high-volume addresses, and transaction chains in a way that raw blockchain explorers do not.
